# Oefening 3.2 - Een notebook met systeeminformatie maken

**Niveau:** Basis  
**Geschatte tijd:** 25 tot 35 minuten

## Doel

Een Jupyter-notebook gebruiken als controleerbaar experimentlogboek.

## Opdracht

Plaats de code in een notebookcel. Voeg een Markdown-cel toe met doel, datum, dataset en conclusie. Voer het notebook schoon uit en exporteer het daarna naar HTML.

Activeer een aparte Python-omgeving.

Installeer de benodigde packages en selecteer in Jupyter de juiste kernel.

Voer de voorbeeldcode uit en noteer versies en foutmeldingen.

Gebruik Restart Kernel and Run All.

Controleer of dezelfde uitvoer opnieuw ontstaat.

Exporteer het notebook naar HTML.

## Werkwijze

1. Probeer de opdracht eerst zelf.
2. Voer de code uit en controleer de tussenresultaten.
3. Voeg minimaal één randgeval toe.
4. Open pas daarna `uitwerking.py` en `uitwerking.md`.
