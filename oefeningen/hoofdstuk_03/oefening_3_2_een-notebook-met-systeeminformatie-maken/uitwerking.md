# Uitwerking 3.2

## Hoe werkt de code?

De code registreert wanneer de controle is uitgevoerd en toont voor ieder verwacht package de gevonden versie. Ontbrekende packages worden gemeld zonder dat de hele controle stopt. Samen met Markdown en uitvoer vormt dit een eenvoudig experimentlogboek.


## Verwachte uitvoer

Het notebook toont de uitvoerdatum en de beschikbare packageversies. Ontbrekende packages worden afzonderlijk gemeld.


## Controleer je uitkomst

- Code en uitleg staan in afzonderlijke cellen.
- Het notebook kan vanaf een schone kernel van boven naar beneden worden uitgevoerd.
- Gevoelige sleutels en persoonsgegevens staan niet in het notebook.

## Verdiepingsopdracht

Voeg een controle toe die waarschuwt wanneer een package buiten een vooraf toegestane versiereeks valt.


## Zelf verder testen

Verander minimaal één invoerwaarde en voeg een randgeval toe. Controleer daarna of de conclusie nog steeds door de uitvoer wordt ondersteund.
