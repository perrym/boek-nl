# Oefening 1.1 - Taken classificeren als AI-probleem

**Niveau:** Basis  
**Geschatte tijd:** 25 tot 35 minuten  
**Benodigde packages:** pandas

## Doel

Leren herkennen welk type AI-techniek bij een bedrijfsprobleem past.

## Opdracht

Maak in Python een kleine tabel met minimaal zes werkzaamheden. Classificeer iedere taak als regressie, classificatie, clustering, generatieve AI of geen AI. Laat Python daarna het aantal taken per categorie tellen.

Python (www.python.org) is een veelgebruikte programmeertaal voor data-analyse, machine learning en AI. In dit boek gebruiken we Python als vaste programmeertaal voor de voorbeelden en oefeningen. Zo kunnen de verschillende technieken op een consistente en praktische manier worden uitgewerkt.

Werk stap voor stap:


1. Lees de opdracht en bepaal de gewenste invoer en uitvoer.

2. Maak eerst de kleinste werkende versie.

3. Voer de code uit en controleer iedere tussenstap.

4. Vergelijk de uitvoer met de verwachte uitkomst.

5. Voeg één randgeval toe en beschrijf wat je daarvan leert.

Hint: werk in kleine stappen en verander steeds maar één onderdeel tegelijk.

## Werkwijze

1. Probeer de opdracht eerst zelf.
2. Voer de code uit en controleer de tussenresultaten.
3. Voeg minimaal één randgeval toe.
4. Open pas daarna `uitwerking.py` en `uitwerking.md`.
