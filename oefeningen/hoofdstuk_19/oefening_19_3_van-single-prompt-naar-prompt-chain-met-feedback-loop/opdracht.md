# Oefening 19.3 - Van single prompt naar prompt chain met feedback loop

**Niveau:** Gemiddeld tot gevorderd  
**Geschatte tijd:** 45 tot 60 minuten

## Doel

Een complexe taak opdelen in controleerbare prompts en een onafhankelijke reviewstap toevoegen.

## Opdracht

Kies een korte technische of zakelijke tekst. Ontwerp eerst één prompt die tegelijk feiten, analyse en aanbevelingen vraagt. Ontwerp daarna een prompt chain met minimaal drie stappen: feitextractie, analyse en kritische review. Vergelijk beide aanpakken op traceerbaarheid, ontbrekende informatie en ongefundeerde conclusies.

## Werkwijze

1. Probeer de opdracht eerst zelf.
2. Voer de code uit en controleer de tussenresultaten.
3. Voeg minimaal één randgeval toe.
4. Open pas daarna `uitwerking.py` en `uitwerking.md`.
