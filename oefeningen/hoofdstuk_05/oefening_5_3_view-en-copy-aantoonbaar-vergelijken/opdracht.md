# Oefening 5.3 - View en copy aantoonbaar vergelijken

**Niveau:** Basis  
**Geschatte tijd:** 25 tot 35 minuten  
**Benodigde packages:** numpy

## Doel

Begrijpen wanneer een wijziging in een slice de oorspronkelijke array verandert.

## Opdracht

Maak een array, neem een view en een echte kopie. Wijzig beide en toon het effect op de originele array.



Werk stap voor stap:


1. Maak de array of matrix met de opgegeven waarden.

2. Controleer eerst shape en datatype voordat je gaat rekenen.

3. Voer de bewerking uit met NumPy.

4. Print zowel de invoer als het resultaat.

5. Controleer handmatig één waarde en voeg daarna een randgeval toe.

Hint: Gebruik eerst een kleine array. Daardoor zie je sneller wat een index, view of vectorbewerking werkelijk doet.

## Werkwijze

1. Probeer de opdracht eerst zelf.
2. Voer de code uit en controleer de tussenresultaten.
3. Voeg minimaal één randgeval toe.
4. Open pas daarna `uitwerking.py` en `uitwerking.md`.
